= VocTool

This project provides a tool to convert WAVE file into 8bit Creative VOC files, including ADPCM compression.
Currently 2bit, 2.6bit and 4bit ADPCM are supported.

The resulting VOC file is always in mono.

== Usage of encoder

[source]
.Usage of voctool
----
Usage: voctool -i INPUT -o OUTPUT [ -f FREQUENCY ] [ -c COMPRESSION ] [ -n NORMALIZE ] [ -s SHAPING ] [ -r RESAMPLER ] 

Program to convert WAVE files into VOC files including optional ADPCM compression.
Conversion from VOC to WAVE is also supported.
File is converted to mono. If a frequency is give then the file is also resampled
to the given frequency. Otherwise the sample frequency of the WAVE file is kept.

Compression formats:
  PCM    - unsigned integer 8-bit per sample
  ADPCM4 - ADPCM 4-bit per sample
  ADPCM3 - ADPCM 2.6-bit per sample (3 samples per byte)
  ADPCM2 - ADPCM 2-bit per sample


options:
  -i, --input        Name of the input file
  -o, --output       Name of the output file
  -f, --frequency    Frequency of output file in hertz
  -c, --compression  Compression to be used. Options: PCM, ADPCM4, ADPCM3, ADPCM2 ( default: ADPCM4 )
  -n, --normalize    Normalize audio to given fraction, e.g. 0.9
  -s, --shaping      Noise shaping for ADPCM (as in ADPCM-XQ). Options: off, dynamic (adapts to the audio), static (high-pass, same as 1.0) or a fixed weight w with -1 < w <= 1. Positive weights move noise to high frequencies, negative to low frequencies. ( default: off )
  -r, --resampler    Resampler quality (libsamplerate). Options: best, medium, fast, linear ( default: best )
----

== Examples
[source,shell]
.Encoding a WAVE file into VOC format. A conversion to 8000Hz and ADPCM4 compression is done. The volume is normalized to 70%.
----
voctool -i sound.wav -f 8000 -c ADPCM4 -o sound.voc -n 0.7
----

[source,shell]
.Decoding a VOC file into WAVE format. Currently decoding VOC files does not support changing of the frequency or compression. The WAVE will always be 8bit PCM.
----
voctool -i sound.voc -o sound.wav
----

== How the ADPCM encoders work

All ADPCM formats are always encoded optimally, so there is no quality setting.
The complete state of the Creative ADPCM decoders is very small: the previous output value (0..255)
plus a step size, which has 4 possible values for ADPCM4, 5 for ADPCM3 and 6 for ADPCM2.
This gives only 1024 (ADPCM4), 1280 (ADPCM3) or 1536 (ADPCM2) possible decoder states.
The encoder uses the Viterbi algorithm over these states to find the sequence of codes whose decoded output
has the smallest possible squared error compared to the input.

== Noise shaping

Optionally the quantization noise of the ADPCM encoders can be shaped with `-s` / `--shaping`,
using the same noise shaping as https://github.com/dbry/adpcm-xq[ADPCM-XQ] by David Bryant.
The error of the previous sample is fed back into the next target sample, which moves the noise
spectrum up or down in frequency. This increases the total noise, but can make it less audible.

* `off` (default): flat noise, the encoding with the smallest possible error.
* `static` or a positive weight up to `1.0`: moves the noise to high frequencies (`1.0` is first-order high-pass shaping).
* a negative weight (greater than `-1.0`): moves the noise to low frequencies.
* `dynamic`: chooses the weight continuously from the spectrum of the audio (comparing the levels above and below 1/6 of
  the sample rate), so the noise is moved to where it is best masked by the signal.

The encoder works on the full precision input samples, so with noise shaping the rounding to 8 bit is shaped as well.

[source,shell]
.Encoding with dynamic noise shaping
----
voctool -i sound.wav -f 11025 -c ADPCM4 -s dynamic -o sound.voc
----

== About Creative ADPCM

Creative ADPCM compresses an 8bit per sample sound file into a 4bit/2.6bit/2bit per sample sound file.
This halves/thirds/quaters the required space, but also decreases the sound quality.
The 2.6bit format (called ADPCM3 here, VOC codec 2) stores three samples per byte using 3 + 3 + 2 bits.
This works by only storing the difference to the previous sample.

== About this encoder

I wrote this encoder because I needed a Creative ADPCM encoder for my MSDOS platform game.
At first I looked for already existing encoders, but there actually were no free encoders available.
The only (non free) encoder I could find was the tool VOCEDIT 2 (see http://www.vogons.org/viewtopic.php?t=8634).
Unfortunately that tool only runs on DOS and it is also a GUI tool that does not support scripting.
I actually got VOCEDIT 2 to run using Dosbox but because of the fact that it is not scriptable and also not free, I decided to build an encoder myself.
